# Storia v0.1.0 — Preview

Storia's first public preview brings ideas, drafts, relationships, and revision history into one writing workspace.

## Highlights

- Capture a line or scene quickly, then grow an idea into an article.
- Connect material with typed relationships and explore the structure as a graph.
- Record the intent and payoff state of foreshadowing links.
- Resume from per-item next-step notes and rediscover dormant or isolated material.
- Write in Markdown with live preview and focus mode.
- Read in horizontal or Japanese vertical layout.
- Save revision snapshots, compare changes, and branch from earlier versions.
- Use the interface in Japanese or English.

## Packages

- Windows x64: MSI and NSIS installers
- macOS Apple silicon: aarch64 DMG
- macOS Intel: x86_64 DMG
- Linux x64: AppImage and Debian package

## Preview limitations

- Writing is stored locally in the app WebView.
- Cloud sync, automatic backups, and file import/export are not available.
- Clearing app site data or uninstalling may remove the workspace.
- Packages are not backed by paid Windows or Apple distribution certificates. The operating system may ask for trust confirmation.
- macOS packages use an ad-hoc signature and may still require approval in Privacy & Security.

Keep a separate copy of important manuscripts while evaluating this preview.
